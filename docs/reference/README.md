# Исходные материалы

Здесь сохранены исходные документы, которые первоначально лежали
в корне рабочего каталога и не отслеживались Git:

- `InterSim_Backlog_MVP_v10_Release1_25-10-2026.docx` — backlog v10 от 25.10.2026.
- `Схема БЗ.md` — локальная схема вопросов, грейдов, критериев и anchors.
- `json_schemas_v1.zip` — четыре исходные схемы Interviewer/Evaluator.

Текущую командную документацию следует сверять с
[intersim-docs](https://github.com/intersim-org/intersim-docs).
Это архив происхождения контрактов; он не заменяет актуальные решения команды.
Рабочий контракт этой реализации находится в [HTTP API](../api.md) и `/openapi.json`.
Четыре актуальные схемы v2 находятся в корне репозитория и генерируются
`python -m app.contracts`. Схемы из архивного ZIP сохраняют исторический формат.
Проверенные ревизии соседних репозиториев перечислены в [интеграции](../integration.md).

Материалы не попадают в Docker build context и runtime-образ.
